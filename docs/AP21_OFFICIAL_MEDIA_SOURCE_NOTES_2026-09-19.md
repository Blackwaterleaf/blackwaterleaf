# AP-21 Official Media Source Notes

## Source findings

| Source | Finding | Import consequence |
|---|---|---|
| [Plants of the World Online (POWO)](https://powo.science.kew.org/) | The official Kew service states that it contains names, distributions, descriptions and images. Its public home page shows a credited image and links to Kew terms. | Use POWO for taxonomy and distribution. Do **not** bulk-import a POWO image until the individual taxon page supplies a reusable image and the specific credit/rights statement has been captured. |
| [Kew terms of use](https://www.kew.org/terms-and-conditions) | Kew retains intellectual-property rights in website content. Commercial use requires a licence unless a specific separate licence applies. | POWO images may not be imported merely because a taxon page contains an image. They require an explicit reusable licence or separate written permission. |
| [FishBase citation and copyright statement](https://www.fishbase.se/summary/citation.php) | FishBase states that each photo or drawing has its own copyright statement. Only images marked CC-BY or CC-BY-NC may be reused without further permission, with full attribution and the indication “from FishBase”. | Each Channa image requires individual license inspection. BlackWaterLeaf excludes CC-BY-NC because catalog images can appear alongside commercial marketplace surfaces. |
| [FishBase Channa striata image index](https://www.fishbase.se/photos/ThumbnailsSummary.php?ID=343) | The individual image index confirms that rights remain with the respective photographer/institution and that each image detail page controls the applicable licence. | A species page or a thumbnail page is not itself an import licence. No Channa image is imported before the individual image page confirms a commercial reusable licence. |
| [GBIF multimedia documentation](https://techdocs.gbif.org/en/data-publishing/multimedia-publishing) | GBIF does not host originals. Media records can include a direct media URL, creator, description and license; occurrence data licenses do not automatically govern media. GBIF recommends machine-readable licensing. | GBIF may only serve as a discovery index. A candidate needs a direct image URL, the GBIF occurrence page, a source-institution record, creator and an explicit reusable media license before review. |

## Enforced policy

BlackWaterLeaf excludes Wikipedia and Wikimedia Commons completely. The candidate collector may propose only a review packet. It must never update production data automatically. A candidate is eligible for import only if the exact taxon identity, source record, direct media URL, stable record page, commercially reusable licence, attribution and manual visual match have all been verified. **CC0 and explicit CC-BY 3.0/4.0 are currently accepted; CC-BY-NC, “all rights reserved”, unclear rights and permission-only media are blocked.**

## Current review queue

The current public catalog contains 66 published POWO plant rows and 15 published FishBase aquarium rows without complete image provenance. The duplicate botanical rows represent different source records/cultivars and therefore cannot be collapsed automatically.
