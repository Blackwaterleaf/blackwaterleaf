**Reference:** user-supplied BlackWaterLeaf mobile layout screenshot, reviewed 16 September 2026.

The required direction is a **deep green, image-led living overlay**, not a conventional bright or minimalist dashboard. The implemented layout therefore uses a translucent moss-green visual base, organic image surfaces, lime signal color, and thin luminous borders. The aquatic, terrarium, and AI areas retain their distinct cyan, gold, and violet accents respectively.

The home screen follows the reference hierarchy: compact sensor strip, large nature moment, four image-led realm cards, a central leaf action control, and the fixed mobile navigation bar. The leaf control uses separate round icons for photo, observation, community post, plant, aquarium, terrarium, and AI. Desktop uses the same asset, color, and icon language with a compact text navigation instead of a mobile bottom bar.

All existing data behaviors remain truthful: no disconnected sensor is presented as a live reading, no community activity is invented, and gated account/AI functions keep their existing access rules. The profile, realm, assistant, knowledge, community, account-access, habitat, form, admin, partner, and empty-state surfaces inherit the same visual system.
